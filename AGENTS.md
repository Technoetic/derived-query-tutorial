# Derived Query tutorial

Build and publish only this public educational application to https://technoetic.github.io/derived-query-tutorial/. Never use Sites/chatgpt.site, credentials, private vault data or previous learners' data. New isolated repo; implementers own assigned files and must not commit/push until root integrates.

Apply the installed webapp6 canonical six rules: responsibility modules and CSS layers, class screens/services, async loading with error/stale protection, hash deep links/history/real missing-asset errors, loaded build identity and fresh same-origin version checks with full-document transition on next safe intended navigation. Protect dirty state and saves, including edits during pending checks. No service worker or runtime dependencies.

Use the developer’s configured Aside CLI for browser automation. No Playwright. Keep examples fictional and text-safe; no eval. Query means a pure derived read, not necessarily SQL or network. Do not confuse correcting an already stale value with proving a behavior-preserving refactoring. Finalized historical records can need stored values.

Domain and UI contract and ownership are in PLAN.md. Use Node built-in tests; write meaningful failing tests for new model behavior. Do not touch another worker's files or other repos.
