# QUERY / CAFE

카페 주문을 직접 바꾸며 Martin Fowler의 **Replace Derived Variable with Query**(파생 변수를 질의 함수로 바꾸기)를 배우는 한국어 인터랙티브 튜토리얼입니다.

단가와 수량을 바꾼 뒤 따로 저장한 합계가 어긋나는 상황을 관찰하고, 값을 맞춘 다음 합계를 읽을 때 원본에서 계산하는 방식으로 바꿉니다. 이미 틀린 합계를 바로잡는 **버그 수정**과, 올바른 결과를 보존하며 구조를 바꾸는 **리팩터링**을 구분합니다. 여기서 질의는 원본을 바꾸지 않는 읽기이며 SQL이나 서버 통신을 요구하지 않습니다.

확정된 과거 영수증과 측정으로 필요성을 확인한 성능 캐시는 별도로 판단합니다.

배포 대상: [GitHub Pages](https://technoetic.github.io/derived-query-tutorial/)

## 로컬 실행

Node.js 22 이상이 필요합니다. 런타임과 개발용 외부 패키지가 없어 별도의 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

빌드 후 `http://127.0.0.1:8896/derived-query-tutorial/`에서 실행합니다. 다른 포트는 `npm start -- --port 8897`로 지정합니다.

```sh
npm test
npm run build
```

테스트는 Node 내장 테스트 러너를 사용합니다. 빌드 결과는 `dist/`에 생성됩니다.

## 이 브라우저에 저장되는 내용

주문 실험과 연습 답안·메모는 각각 저장 버튼으로 `localStorage`에 보관합니다. 표시 설정은 변경할 때 저장합니다.

| 키 | 내용 |
| --- | --- |
| `derived-query-tutorial:lab-draft:v1` | 주문 실험 상태 |
| `derived-query-tutorial:practice-draft:v1` | 연습 답안과 메모 |
| `derived-query-tutorial:prefs:v1` | 테마와 움직임 설정 |

로그인이나 서버 동기화는 없습니다. 브라우저 데이터를 지우거나 다른 브라우저·기기를 사용하면 저장 내용을 이어 볼 수 없습니다. 저장소 접근이 차단되면 저장 오류를 안내합니다.

앱은 자체 정적 파일을 불러오며 외부 런타임 SDK, CDN 라이브러리, 분석 도구를 사용하지 않습니다. 서비스 워커도 사용하지 않습니다.

## GitHub Pages 배포와 갱신

저장소의 Pages 소스를 GitHub Actions로 설정해 사용합니다. `.github/workflows/pages.yml`은 `main` 푸시 또는 수동 실행 시 테스트, 빌드, 정적 파일 업로드와 배포를 수행하도록 구성되어 있습니다. 배포 폴더는 `dist/`입니다.

GitHub Pages에서는 이 앱이 응답 캐시 헤더를 직접 지정할 수 없습니다. 로컬 서버의 헤더 설정이 Pages에도 적용된다고 가정하지 않습니다. 로드된 문서의 빌드 ID와 고유 쿼리 매개변수를 붙여 조회한 같은 출처의 `version.json`을 비교하고, 변경을 감지하면 다음 안전한 화면 이동에서 대상 URL을 새 문서로 엽니다. 이때 문서 URL에도 고유 쿼리 매개변수를 붙입니다. 미저장 입력과 저장 중인 작업은 전환 전에 보호합니다. 호스트의 배포 전파와 캐시 동작까지 앱에서 통제할 수는 없습니다.

실행 자산은 빌드 내용에 따른 식별자를 파일명에 포함합니다. 배포 과정은 직전 공개 빌드의 자산을 검증해 함께 보관하도록 구성되어 있습니다. 수업 데이터의 새 조회는 앱 코드 갱신과 별도로 처리합니다.

화면은 해시 URL을 사용합니다. 알 수 없는 해시는 앱의 없는 화면 안내로 연결하며, 존재하지 않는 파일이나 일반 경로를 앱 HTML로 대체하는 SPA fallback은 사용하지 않습니다. 해당 요청은 실제 HTTP 404로 처리합니다.

## 출처와 라이선스

[Martin Fowler의 원문 카탈로그](https://refactoring.com/catalog/replaceDerivedVariableWithQuery.html)를 바탕으로 개념을 설명합니다. 카페 이야기, 한국어 설명, 문제와 코드는 이 튜토리얼을 위해 새로 구성한 예시입니다. 원문이나 유료 웹판을 복제한 자료가 아니며 공식 번역도 아닙니다.
